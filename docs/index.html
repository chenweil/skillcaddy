The problem 问题

Skills drift when every project keeps its own copy. 每个项目各自拷贝 skill，版本迟早会漂移。

If you use multiple AI coding agents across repos, the same skill ends up in three places, slightly different each time. New projects mean more copies. Upstream updates never land.

当你在多个仓库里同时用 AI 编码 Agent，同一个 skill 会散落在三处，各自略微不同。新开项目就要再拷一遍；上游更新也跟不上。

Copy-paste drift

复制即漂移

The same skill lives in three repos, each a week behind the others.

同一个 skill 出现在三个 repo 里，彼此落后一周。

New project tax

新项目税

Every new repo starts with “which skills do I copy this time?”

每次新开仓库都要问：这次该拷哪些 skills？

Agent path chaos

Agent 路径混乱

Claude Code wants `.claude/skills`; others want `.agents/skills`.

Claude Code 要 `.claude/skills`，其他工具要 `.agents/skills`。

How it works 工作原理

One library. Explicit project, global, or Hermes links. 一个中央库。明确的项目、全局或 Hermes 链接。

Skillcaddy never copies skill files into projects. Enable creates an explicit project, shared Agents, or Hermes symlink; disable only removes that symlink. Sources stay safe.

Skillcaddy 从不把 skill 文件复制进项目。启用就是创建明确作用域的项目、全局 Agents 或 Hermes 软链接；禁用只删链接，源文件始终安全。

01

Collect sources

汇总来源

Aggregate official, github, personal, archived, and repo-bundled skills under one AISkills root.

把 official / github / personal / archived 与仓库内 skills 汇总到同一个 AISkills 根目录。

~/AISkills/
official/ github/
personal/ archived/
02

Enable by symlink

软链接启用

Point `/.agents/skills/`, `~/.agents/skills/`, or `~/.hermes/skills/` at the library skill.

把 `/.agents/skills/`、`~/.agents/skills/` 或 `~/.hermes/skills/` 指到库中 skill。

~/AISkills/github/…/tdd
.agents/skills/tdd project
~/.agents/skills/tdd global
~/.hermes/skills/tdd hermes
03

Sync Claude Code

同步 Claude Code

Project links can sync into `.claude/skills/`; global and Hermes enablement remain independent.

项目链接可同步到 `.claude/skills/`；全局和 Hermes 启用彼此独立。

.claude/skills/tdd
→ .agents/skills/tdd

Install 安装

One command. No build step. 一条命令装好。
无需构建。

Skillcaddy ships on npm and Homebrew. Run it once with npx, install it globally, or build it from a clone.

Skillcaddy 已发布到 npm 与 Homebrew。可用 npx 免安装试跑，也可全局安装，或克隆仓库从源码运行。

  • Web manager at 127.0.0.1:4173 Web 管理器默认 127.0.0.1:4173
  • From a clone, link the CLI once: npm run install:cli 克隆形态可一次挂载全局命令：npm run install:cli
  • Library stays in ~/.skillcaddy/library — reinstalls never touch your skills 原件库固定在 ~/.skillcaddy/library，重装升级不动已有 skill
  • Needs Node.js >= 20; macOS / Linux native, Windows needs Developer Mode 需要 Node.js >= 20；macOS / Linux 原生支持，Windows 需开启开发者模式
Open repository 打开仓库 Read the docs 阅读文档
terminal 
# one-shot run — installs nothing
npx skillcaddy

# persistent global command
npm install -g skillcaddy
skillcaddy start ~/code/my-project

# Homebrew
brew install chenweil/tap/skillcaddy

# one-line installer
curl -fsSL https://raw.githubusercontent.com/chenweil/skillcaddy/main/scripts/install.sh | bash

# or build from source
git clone https://github.com/chenweil/skillcaddy.git
cd skillcaddy && npm install && npm start

# optional: install manager skill globally
npm run install:manager

Platforms 平台

macOS 与 Linux 原生支持目录软链接。Windows 需开启开发者模式，或以提升权限运行。
